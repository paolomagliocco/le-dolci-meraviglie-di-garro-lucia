# Biscotti Decorati - Astro

## Avvio locale

1. Installa Node.js LTS.
2. Apri questa cartella nel terminale.
3. Esegui:

```bash
npm install
npm run dev
```

4. Apri nel browser l'indirizzo mostrato da Astro, normalmente:

http://localhost:4321

## Build produzione

```bash
npm run build
```
